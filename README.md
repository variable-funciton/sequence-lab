# 数列のシミュレーション（数学IB 後期）

Streamlit Community Cloud で公開する、数列の学習用 Web アプリです。
**Main file path は従来どおり `LevelPayment.py`** のままで動きます（中身はページ一覧に変わりました）。

## ページ構成

| ページ | 内容 | 関連課題 |
|---|---|---|
| 等差数列とその和 | 項と和のグラフ、和が最大になる n、初めて負になる項、和の公式の図解 | 後期課題9 |
| 等比数列とその和 | 一般項と和の公式。公比 r の 6 つの場合（0<r<1, r=1, r>1, −1<r<0, r=−1, r<−1）を強調表示・一覧比較。和の公式の導き方 | 後期課題10 |
| いろいろな数列の和（収束・発散） | 1/n、1/n²、1/√n、1/n⁴、1/{n(n+1)}、1/2ⁿ、交代級数、1/nᵖ の部分和を 100 万項まで比較（対数目盛）、1 項ずつ足す様子、バーゼル問題（π²/6、√(6S) で π を近似）、オレームの方法・分数の差による評価 | 後期課題10（発展） |
| 単利と複利 | 単利（等差数列）と複利（等比数列）の比較、毎年減る投資、72 の法則 | 後期課題10 |
| 漸化式で見るローン返済 | `a_{n+1} = (1+r)a_n − P` を 1 年ずつ進める。完済・残クレ・返済額固定、特性方程式と一般項 | 後期課題12 |
| ローン返済で学ぶ漸化式（月次・総合） | 元利均等返済の解法、一般項と数値の比較、総支払額、返済不能シナリオ、用語集、リボ払い、残クレ、まとめ、設備投資（12 タブ。loan_recurrence_app_v2.py を移植） | 後期課題12（発展） |
| 元利均等返済（月次・実務版） | 旧 LevelPayment.py の画面（変更なし） | 発展 |

### 物理・各学科への応用

| 分野 | ページ | 内容 | 使う数列 |
|---|---|---|---|
| プログラミング | ニュートン法 | √a の漸化式（長方形が正方形に近づくアニメーション、正しい桁を色分けした 40 桁の表）、相加相乗平均と誤差の式 e_{n+1} = e_n²/(2x_n)、二分法との比較（誤差の対数グラフ）、接線で考えるニュートン法（接線のアニメーション、行ったり来たりする例）、割り算を使わない 1/a、Python のプログラム例 | 非線形の漸化式・2 次収束 |
| プログラミング | ハノイの塔と計算時間 | 円盤を動かすアニメーション（3 段階のしくみ）、Tₙ = 2Tₙ₋₁ + 1 と一般項 2ⁿ − 1、再帰のプログラム、n・n²・n³・2ⁿ の計算時間の比較（64 枚の伝説） | 漸化式・指数的増加 |
| プログラミング | 円周率の近似（アルキメデス） | 内接・外接正多角形の漸化式（調和平均・相乗平均）、正 96 角形、桁落ちする式と工夫した式、ライプニッツ・バーゼル・アルキメデス・ガウス＝ルジャンドルの速さ比べ | 連立漸化式・収束の速さ |
| 都市 | 交通渋滞のセルオートマトン | ナーゲル・シュレッケンベルグ模型、円形道路と時空図のアニメーション、密度と流量の基本図 | 位置の漸化式 |
| 都市 | 環境汚染と自浄作用 | 湖：cₙ₊₁ = (1 − k)cₙ + L と定常状態、途中で流入を減らす、目標濃度に達する年。川：下流へ等比数列で減る | 漸化式 pxₙ + q・等比数列 |
| 生物・社会 | ロジスティック写像とカオス | xₙ₊₁ = axₙ(1 − xₙ)、くもの巣図、分岐図、初期値のわずかな差が広がる様子 | 非線形の漸化式 |
| 生物・社会 | 感染症の流行モデル（SIR） | S・I・R の連立漸化式、R₀ と流行の山、接触を減らす対策の効果、集団免疫の目安 | 連立漸化式 |
| 物理 | 空気抵抗のある斜方投射 | 抵抗なし（青）と抵抗あり（赤）を同時に投げるアニメーション、漸化式（オイラー法）での計算、角度と飛距離のグラフ（最もよく飛ぶ角度は 45° より小さい）、終端速度 | 漸化式 |
| 物理 | ボールの跳ね返り | 落ちてはね返るアニメーションと高さのグラフ。反発係数 e。高さ h₀e²ⁿ、止まるまでの道のり・時間（無限等比級数）、高さと時刻のグラフ | 等比数列・無限等比級数 |
| 機械 | 標準数（ルナール数列） | R5〜R40 と理論値 10^(k/n)、最も近い標準数、対数目盛 | 等比数列 |
| 機械 | 減衰振動の振幅 | ばねにつけたおもりの振動のアニメーション（ダンパー／床の摩擦）。粘性減衰（振幅が r 倍ずつ）と摩擦（d ずつ）、対数減衰率 | 等比数列・等差数列 |
| 電気 | 抵抗器の E 系列 | E6・E12・E24、許容差の範囲とすき間、最も近い値 | 等比数列 |

各ページの「例題を読み込む」で、課題と同じ数値を読み込めます。

## ファイル構成

```
LevelPayment.py        エントリーポイント（ページ一覧はここで管理）
views/                 各ページ
utils/sequences.py     数列の計算（Fraction で厳密計算、Streamlit に依存しない）
utils/level_payment.py 月次ローンの計算クラス（旧 LevelPayment.py から移動）
utils/applied.py       物理・各学科への応用ページの計算（Streamlit に依存しない）
utils/anim.py          ブラウザで動くアニメーション（assets/*.html）をページに埋め込む
utils/series.py        いろいろな数列の和（部分和・バーゼル問題）
utils/newton.py        ニュートン法・二分法（桁数の多い小数 Decimal で計算）
utils/models.py        ハノイの塔・交通渋滞・汚染と自浄・ロジスティック写像・SIR・円周率
assets/                アニメーション（bounce・damping・transient・projectile・newton_rect・newton_tangent・hanoi・traffic の .html と共通部品 anim_common.js）
                       生徒のブラウザの中で動くので、全員が同時に再生してもサーバーに負荷がかからない
tests/test_sequences.py 課題9・10・12 の数値で検証するテスト
tests/test_applied.py  応用ページの計算のテスト（国税庁の減価償却の例などで検証）
```

## ローカルでの確認

```bash
pip install -r requirements.txt
streamlit run LevelPayment.py
python -m tests.test_sequences
python -m tests.test_applied
```
